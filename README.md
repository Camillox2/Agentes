## Como usar

Abra o arquivo do perfil desejado e use seu conteúdo como instrução de sistema ou contexto do agente. Forneça também os dados do caso e a jurisdição relevante. Os links legais são pontos de partida: peça ao agente para verificar a redação vigente, regulamentação, jurisprudência e normas estaduais/municipais aplicáveis no momento da consulta.

Os perfis apoiam análise e produção de rascunhos; não substituem profissionais habilitados nem garantem conformidade. Não envie dados pessoais ou sigilosos sem necessidade.

**Referências verificadas em 3 de outubro de 2026.** A legislação muda; cada perfil exige nova verificação para assuntos atuais.
